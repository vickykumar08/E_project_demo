# Embroprint – Modern E-Commerce Apparel Showcase (`E_project_demo`)

A high-converting, modern e-commerce showcase web application for custom printed and embroidered apparel inspired by [Embroprint.in](https://embroprint.in/). Built with **React 19, TypeScript, Vite, and modern Vanilla CSS**.

---

## 🌟 Key Features

- **112+ Curated Sample Products**:
  - Anime & Manga Vault (Luffy Gear 5, Gojo Satoru, Sukuna, Zoro, Itachi, Tanjiro, etc.)
  - Bikes & Supercars Motorsport (Porsche 911 Turbo, Nissan Skyline GT-R R34, Supra MK4, etc.)
  - Hoodies & Heavy Fleece Drops (320 GSM loopknit brushed fleece)
  - Cotton Polos & Corporate Merch (220 GSM combed honeycomb pique)
  - Portrait & Pet Lineart Studio (Hand-digitized couple outlines, pet silhouettes)
  - Custom Studio & Brand Logo Builder (Startup merch, college batches, signatures)
  - Streetwear & Graphic Drops (Acid wash Shinjuku, Japanese koi, mecha)
- **Default "All Collection" View**: Instant access to all 112 product cards upon initial page load with dynamic category pill counters.
- **Interactive Product Customizer & Mockup Studio**:
  - Live garment canvas switcher (Oversized Round Neck Tee, Honeycomb Polo, Streetwear Hoodie, Modern Sweatshirt)
  - 7 fabric color swatches with instant previews
  - Custom artwork / logo upload simulation with live placement preview (Center Chest, Left Pocket, Full Back, Left Sleeve)
  - Size selection (S to XXL) with interactive Size Guide modal
  - Tiered bulk discounts calculation
- **Light & Dark Mode Support**:
  - Dual theme with instant toggle in the sticky navbar
  - Persisted to `localStorage` and respects system preferences
- **Slide-Over Cart Drawer & Simulated Checkout**:
  - Real-time cart drawer with quantity steppers and express shipping meter
  - Promo code engine (`FIRST10` for 10% off)
  - 2-step mock checkout with confetti celebration and Order ID generation

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Vanilla CSS with comprehensive CSS custom properties (variables)
- **Icons**: Lucide React
- **FX**: Canvas Confetti

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized production bundle will be built in the `dist/` directory.
